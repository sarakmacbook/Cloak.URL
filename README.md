## ✨ What is this?

**cloak.link** is a minimal, privacy-first URL shortener you host yourself. No sign-ups, no tracking, no analytics — just short links.

- **Zero dependencies** — Python standard library only
- **No database server** — SQLite, auto-created
- **No open ports** option — Cloudflare Tunnel support
- **Password-protected links** — optional
- **Self-destructing links** — optional expiration

## 🚀 Quick Start (Ubuntu)

### Step 1: Download

```bash
curl -L -o cloak.link.zip https://github.com/yourusername/cloak.link/releases/latest/download/cloak.link.zip
unzip cloak.link.zip && cd cloak.link
```

Or with git:

```bash
git clone https://github.com/yourusername/cloak.link.git
cd cloak.link
```

### Step 2: Run Installer

```bash
bash install.sh
```

The installer will ask:
1. **Deployment method** — pick `1` for Cloudflare Tunnel (easiest) or `2` for Nginx
2. **Port** — press Enter for `3000`
3. **Cloudflare token** — paste from [one.dash.cloudflare.com](https://one.dash.cloudflare.com) (Tunnel only)
4. **Domain** — e.g. `mybrand.com`
5. **Add more domains?** — `y` or `n`, up to 10 total

That's it. The installer handles Docker, config files, and everything else.

### Step 3: Access

```
https://mybrand.com        ← your shortener
https://mybrand.com/abc123 ← example short link
```

## 🌐 Deployment Methods

### Method 1: Cloudflare Tunnel (Easiest ⭐)

No open ports. No static IP. Works behind any router.

```bash
bash install.sh
# → 1) Cloudflare Tunnel
# → Paste your tunnel token
# → Enter domain: mybrand.com
```

**Get your token:**
1. Go to [one.dash.cloudflare.com](https://one.dash.cloudflare.com)
2. **Networks → Tunnels → Create a tunnel**
3. Name it `cloak-link`, pick **Docker**
4. Copy the token, paste into installer

**Add hostname in Cloudflare:**
- Subdomain: `mybrand.com`
- Service: `http://cloak:3000`
- Save → wait for "Healthy"

### Method 2: Nginx (VPS)

For servers with a static IP.

```bash
bash install.sh
# → 2) Nginx
# → Enter domain: mybrand.com
# → sudo bash nginx/install-nginx.sh
# → sudo certbot --nginx   # optional HTTPS
```

**Point DNS:**
```
Type  Name           Value
A     mybrand.com    YOUR_SERVER_IP
```

## ⚙️ Configuration

All settings are in `.env` (auto-generated by installer):

```bash
# Edit config
nano .env

# Restart
docker compose up -d
```

| Variable | Default | Description |
|----------|---------|-------------|
| `PORT` | `3000` | Internal port |
| `BASE_URL` | `http://localhost:3000` | Your domain |
| `MAX_LINKS` | `10000` | Max total links |
| `TUNNEL_TOKEN` | — | Cloudflare token (Tunnel only) |

## 🔌 API

```bash
# Create a short link
curl -X POST https://mybrand.com/api/shorten   -H "Content-Type: application/json"   -d '{"url":"https://example.com","path_prefix":"blog","custom_code":"post-2026"}'

# Response
{"short_url":"https://mybrand.com/blog/post-2026","code":"post-2026"}
```

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/shorten` | POST | Create short link |
| `/api/urls` | GET | List your links |
| `/api/stats` | GET | Link count |
